# Маркус И.Д. — Юрист

Статический сайт-визитка: обычный HTML + CSS + JS, сборка не нужна.
До 01.10.2026 был на React + Vite (история — в git, коммиты до перевода на HTML).

## Структура

- `index.html` — вся страница
- `css/style.css` — стили (собранный Tailwind + в конце файла свои: появление блоков, лайтбокс)
- `js/main.js` — шапка при прокрутке, мобильное меню, появление блоков, лайтбокс документов
- `assets/` — фото и документы

Классы в `index.html` — Tailwind. Новый класс, которого нет в `css/style.css`, работать не будет —
стили для него дописывать в конец `css/style.css` вручную.

## Посмотреть локально

```bash
python -m http.server 8000
```

и открыть http://127.0.0.1:8000/

## Домены

- `idmarkus.ru` / `www.idmarkus.ru` — основной
- `idmarcus.ru` / `www.idmarcus.ru` (старое написание) — 301-редирект на `idmarkus.ru`
